# beCook components

La carpeta `ui` contiene piezas visuales pequeñas y reutilizables sin lógica de negocio.
La carpeta `layout` contiene estructura de página compartida.
La carpeta `features` agrupa componentes visuales ligados al dominio de beCook, como selectores de días o previews de menú.

Mantén storage, API calls y decisiones de datos en las páginas o librerías existentes.
